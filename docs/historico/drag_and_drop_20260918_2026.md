# Implementação de Drag and Drop (Arrastar e Soltar)
**Data:** 18 de Setembro de 2026

## O que foi feito
Adicionamos suporte nativo (HTML5) para arrastar e soltar as atividades no layout semanal (Visão Grid/Trello).
A alteração ocorreu na renderização dos cards para incluir atributos de arraste, na renderização das colunas para atuar como zonas de recepção e na injeção de um novo script que gerencia os eventos.

## 1. Estado Anterior (Antes) - app.js
O card da atividade e a coluna do dia eram renderizados sem marcações de arraste:

```javascript
// Renderização do Card
return `
<div class="p-2 mb-2 bg-[var(--bg-color)] border border-[var(--border-color)] rounded shadow-sm flex flex-col group relative hover:shadow-md transition">
    <div class="flex flex-wrap items-center mb-1 gap-1">
```

```javascript
// Renderização da Coluna
<div class="p-3 border-b border-[var(--border-color)] bg-[var(--bg-color)] flex justify-between items-center cursor-pointer hover:text-[var(--primary-color)] transition" title="Abrir Agenda">
    <span class="font-bold truncate">${dayName}</span>
    <span class="text-xs text-[var(--text-secondary)] bg-[var(--border-color)] px-2 py-1 rounded-full">${displayDate}</span>
</div>
<div class="p-3 flex-1 overflow-auto space-y-2">
    ${activitiesHTML}
</div>
```

## 2. Estado Novo (Depois) - app.js e index.html
Adicionamos os atributos nativos `draggable`, `data-task-id` e a classe `.day-dropzone`.

```javascript
// Renderização do Card
return `
<div draggable="true" data-task-id="\${a.id}" data-current-date="\${a.date}" class="task-card p-2 mb-2 bg-[var(--bg-color)] border border-[var(--border-color)] rounded shadow-sm flex flex-col group relative hover:shadow-md transition cursor-grab">
    <div class="flex flex-wrap items-center mb-1 gap-1">
```

```javascript
// Renderização da Coluna
<div class="p-3 border-b border-[var(--border-color)] bg-[var(--bg-color)] flex justify-between items-center cursor-pointer hover:text-[var(--primary-color)] transition" title="Abrir Agenda">
    <span class="font-bold truncate">${dayName}</span>
    <span class="text-xs text-[var(--text-secondary)] bg-[var(--border-color)] px-2 py-1 rounded-full">${displayDate}</span>
</div>
<div class="p-3 flex-1 overflow-auto space-y-2 day-dropzone" data-date="\${dateStr}">
    ${activitiesHTML}
</div>
```

Além disso, foi criado o arquivo `js/dragAndDrop.js` e inserido no `index.html` logo acima da tag de fechamento do `body`.

## 3. Plano de Rollback / Desfazer
Se houver problemas no arraste em dispositivos touch ou quebras no layout, reverta da seguinte maneira:

1. Vá em `js/app.js`, procure por `draggable="true" data-task-id="${a.id}" data-current-date="${a.date}" class="task-card` e volte para `class="` removendo os atributos de data e arraste, além das classes `task-card` e `cursor-grab`.
2. Em `js/app.js`, procure por `day-dropzone" data-date="${dateStr}"` na construção do Grid Semanal e apague esses atributos.
3. No arquivo `index.html`, remova a tag `<script src="js/dragAndDrop.js"></script>`.
4. (Opcional) Delete o arquivo `js/dragAndDrop.js`.
